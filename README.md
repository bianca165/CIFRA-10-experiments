# CIFRA-10-experiments

This repository contains experiments with Denoising Autoencoders on the CIFAR-10 dataset. The primary goals are to denoise images and perform unsupervised clustering on the learned latent representations. The project includes two distinct implementations: one using standard machine learning libraries (PyTorch, Scikit-learn) and another built from scratch using NumPy.

## Features

*   **Data Loading & Preprocessing**: Loads the CIFAR-10 dataset, normalizes images, and adds Gaussian noise.
*   **Dual Implementations**:
    *   **Library-Based**: A Denoising Autoencoder built with PyTorch and clustering with Scikit-learn's KMeans.
    *   **From-Scratch**: A Denoising Autoencoder and KMeans clustering algorithm built entirely with NumPy.
*   **Hyperparameter Tuning**: Implements K-Fold cross-validation and a simple grid search for optimizing the learning rate.
*   **Unsupervised Clustering**: Applies KMeans clustering to the latent space vectors generated by the autoencoder.
*   **Clustering Evaluation**: Assesses clustering performance using metrics like Silhouette Score, Calinski-Harabasz Index, and Adjusted Rand Index (ARI).
*   **Optimal Cluster Selection**: Includes scripts for the Elbow Method and Silhouette Analysis to determine the optimal number of clusters (`k`).
*   **Model Explainability**: Utilizes SHAP (`DeepExplainer` for the PyTorch model and `KernelExplainer` for the scratch model) to interpret feature importance.
*   **Visualization**: Provides utilities for visualizing original vs. reconstructed images, training loss curves, and 2D projections of latent space clusters.

## Implementations

### 1. Library-Based (`lib/`)

This version leverages popular libraries for rapid development and performance.
*   **Autoencoder**: Implemented as a `torch.nn.Module` with dense layers.
*   **Training**: Uses PyTorch's automatic differentiation and the Adam optimizer.
*   **Clustering**: Employs `sklearn.cluster.KMeans`.
*   **Explainability**: Uses `shap.DeepExplainer`, which is optimized for deep learning models.

### 2. From-Scratch (`scr/`)

This version is built from the ground up to demonstrate a fundamental understanding of the underlying algorithms.
*   **Autoencoder**: Implemented with custom `DenseLayer` and `Sigmoid` classes in NumPy, including manual backpropagation.
*   **Training**: The training loop, batching, and gradient updates are all implemented manually.
*   **Clustering**: A custom `KMeansScratch` class implements the KMeans algorithm.
*   **Explainability**: Uses `shap.KernelExplainer`, a model-agnostic explainer suitable for the custom NumPy model.

## Setup and Usage

### 1. Installation

First, clone the repository:
```bash
git clone https://github.com/bianca165/cifra-10-experiments.git
cd cifra-10-experiments
```

Install the required dependencies. The main libraries used are:
*   `numpy`
*   `matplotlib`
*   `scikit-learn`
*   `tensorflow` (for `cifar10.load_data()` in `autoencoder_analysis.py`)
*   `torch`
*   `shap`

You can install them using pip:
```bash
pip install numpy matplotlib scikit-learn tensorflow torch shap
```

The CIFAR-10 dataset is included in the `data/` directory.

### 2. Running the Experiments

You can run either the library-based or the from-scratch implementation.

**To run the library-based (PyTorch) version:**
```bash
python lib/main_lib.py
```

**To run the from-scratch (NumPy) version:**
```bash
python scr/main_scr.py
```

Both scripts will perform the following steps:
1.  Load and preprocess the data.
2.  Run cross-validation to evaluate the model.
3.  Train the final autoencoder model.
4.  Generate and display the training loss curve.
5.  Perform KMeans clustering on the latent space.
6.  Evaluate and print clustering metrics.
7.  Visualize the clustered latent space and sample image reconstructions.
8.  Generate and display SHAP explanations.
